# Upgrade calcit-viewer to Calcit 0.13.77

- Raise the compiler baseline from 0.13.32 to 0.13.77 and pin the JavaScript runtime package to the exact matching version.
- Install Calcit modules strictly and JavaScript packages immutably before verifying compiler/runtime alignment.
- Pin the maintained setup action and restrict the workflow token to read-only repository contents.
- Preserve viewer behavior, application version 0.1.2, push-only deployment, and the reviewed static quality budget.

## Blocked validation

- `yarn install --immutable` passes with `@calcit/procs` 0.13.77.
- `caps --strict --ci` is currently blocked by five pre-existing dependency-version divergences in the Respo/Lilac graph.
- After a non-strict module install, Calcit 0.13.77 canonicalizes the root snapshot but `--check-only` stops at the published `Respo/respo.calcit@0.16.82`: `respo.core/defcomp` still has the legacy whole-`Dynamic` macro schema rejected by 0.13.77.
- No pull request should be opened until a compatible published Respo dependency graph is available and the full workflow passes.

## 验证阻塞

- `yarn install --immutable` 已在 `@calcit/procs` 0.13.77 下通过。
- `caps --strict --ci` 当前被 Respo/Lilac 依赖图中 5 组既有版本分歧阻塞。
- 非 strict 安装模块后，Calcit 0.13.77 能规范化根 Snapshot，但 `--check-only` 会停在已发布的 `Respo/respo.calcit@0.16.82`：`respo.core/defcomp` 仍使用 0.13.77 拒绝的旧式整体 `Dynamic` 宏 schema。
- 在兼容的 Respo 依赖图发布且完整 workflow 通过前，不应创建 PR。
